# Open-Source & Useful Tools Directory

[Open Source Tools. No Signups. Right in your browser](https://nosignups.net) — A definitive collection of quick-access tools.

---

## 🎥 Video & Media
- **[CompressO](https://compresso.codeforreal.com)** ([GitHub](https://github.com/codeforreal1/compressO/releases)) - Browser-based video compression.
- **[HandBrake](https://handbrake.fr/)** - The industry standard open-source video transcoder and compressor. 
- **[Kdenlive](https://kdenlive.org/)** - A powerful open-source multi-track video editor.
- **[FFmpeg](https://ffmpeg.org/)** - A complete, cross-platform command-line solution to record, convert, and stream audio and video.
- **[Open Converter](https://github.com/OpenConverterLab/OpenConverter/releases)** - Accessible media converter lab.

## 📸 Photography & Image Processing
- **[Caesium Image Compressor](https://saerasoft.com/caesium/)** ([GitHub](https://github.com/Lymphatus/caesium-image-compressor/releases)) - Offline image compression tool.
- **[Darktable](https://www.darktable.org/)** - An open-source photography workflow application and RAW developer, perfect for manual exposure calibration and non-destructive editing.
- **[RawTherapee](https://www.rawtherapee.com/)** - A powerful, cross-platform raw image processing program.

## 🎵 Audio & Music
- **[SpotBye](https://github.com/spotbye)** - Spotify ad-blocker and utility.
- **[SpotiFLAC](https://github.com/spotbye/SpotiFLAC/releases)** - Tool for downloading lossless FLAC audio.
- **[yt-dlp](https://github.com/yt-dlp/yt-dlp)** - A highly capable command-line audio/video downloader supporting hundreds of sites.

## 📝 Workspaces & Note Taking
*Note: Some popular tools in this space are free but closed-source. True open-source alternatives are highlighted.*
- **[AppFlowy](https://appflowy.io/)** - The open-source alternative to Notion. You are in charge of your data and customizations.
- **[Logseq](https://logseq.com/)** - A privacy-first, open-source knowledge base that works on top of local plain-text Markdown files.
- **[Obsidian](https://obsidian.md)** - A flexible, local-first application for writing notes (Free & Local, but Closed-Source).
- **[Notion](https://www.notion.com)** - An all-in-one digital workspace (Proprietary/Closed-Source).

## 🎨 Creative Web Tools & Assets
- **[effect.app](https://effect.app/)** - Professional browser-based image and video effects (Needs Signup).
- **[tooooools.app](https://www.tooooools.app)** - Free minimalist and lo-fi effects for online media processing.
- **[artkit.cc](https://artkit.cc)** - Freemium creative design tool suite.
- **[pixelcrash.xyz](https://www.pixelcrash.xyz)** - Digital distortion, glitch effects, and datamoshing-inspired animations.

## 💻 Development Ecosystem
- **[Supabase](https://supabase.com/)** - An open-source Firebase alternative providing a Postgres database, Authentication, instant APIs, and Realtime subscriptions.
- **[Vue.js](https://vuejs.org/)** & **[Nuxt](https://nuxt.com/)** - The approachable, versatile, and performant open-source JavaScript framework and its intuitive meta-framework for building web interfaces.
- **[Tailwind CSS](https://tailwindcss.com/)** - A utility-first CSS framework for rapidly building custom user interfaces.
- **[Doppler](https://www.doppler.com/)** - A centralized environment variable and secrets management tool for development teams.
- **[Icones](https://icones.js.org)** - An open-source icon explorer featuring thousands of free icons.
- **[LogoIpsum](https://logoipsum.com)** - Free placeholder temporary logos for UI/UX mockups.
- **[Google Fonts](https://fonts.google.com)** - A library of free, open-source fonts and icons.
- **[Three.js](https://threejs.org)** - A cross-browser JavaScript library for rendering 3D computer graphics.

## 🤖 Artificial Intelligence
- **[Ollama](https://ollama.com)** - An open-source application that lets you download and run large language models locally on your own hardware.
- **[Uno Router](https://unorouter.com/en)** - A gateway to free AI models.
- **[Composio](https://composio.dev)** - An integration platform connecting AI agents and LLMs to over 1,500 external software applications.
- **[LM Studio](https://lmstudio.ai/)** - Discover, download, and run local LLMs with a clean graphical interface.
