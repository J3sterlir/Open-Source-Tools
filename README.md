# Open-Source-Tools
A list of useful open source tools

- [Open Source Tools. No Signups. Right in your browser](https://nosignups.net) (Definitive List Of Tools)

- Video
  * [CompressO Video Compression](https://compresso.codeforreal.com)
    +  [CompressO Github](https://github.com/codeforreal1/compressO/releases)
   
- Photo
  * [Caesium Image Compressor](https://saerasoft.com/caesium/)
    + [Caesium Github](https://github.com/Lymphatus/caesium-image-compressor/releases)

- Media Converter
  * [Open Converter](https://github.com/OpenConverterLab/OpenConverter/releases)
 
- Music Downloaders
  * [SpotBye](https://github.com/spotbye)
    + [SpotiFLAC](https://github.com/spotbye/SpotiFLAC/releases)

---
### Other

- For Creatives / Artists
  * [effect.app](https://effect.app/) (Professional effects to images and videos in your browser / Needs Signup)
  * [tooooools.app](https://www.tooooools.app) (free minimalist and lo-fi effects for image and video processing online)
  * [artkit.cc](https://artkit.cc) (Creative Design Tools / freemium)
  * [pixelcrash.xyz](https://www.pixelcrash.xyz) (digital distortion, glitch effects, and datamoshing-inspired animations for videos and images)

- Devs
  * [Icones](https://icones.js.org) (Free Icons)
  * [LogoIpsum](https://logoipsum.com) (Temporary Logos)
  * [GoogleFonts](https://fonts.google.com)
  * [Three.js](https://threejs.org) (3D computer graphics directly inside a web browser)

- AI
  * [Uno Router](https://unorouter.com/en) (Free AI Models)
  * [Ollama](https://ollama.com) (free, open-themed software tool that lets you download and run large language models directly on your own computer)
  * [Composio](https://composio.dev) (Connects AI agents and Large Language Models (LLMs) to over 1,500 external software applications and tools)
